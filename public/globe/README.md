# Globe-texturen

Equirectangulaire aardtexturen voor de club-globe (`/[lang]/club-globe`).

- `earth-day.jpg` — NASA Blue Marble (daglicht), gebruikt in het lichte thema.
- `earth-night.jpg` — NASA Earth at Night (stadslichten), gebruikt in het donkere thema.
- `earth-topology.png` — hoogtekaart, gebruikt als bump map voor terreinreliëf.

Herkomst: gekopieerd uit https://github.com/vasturiano/three-globe (MIT),
`example/img/`. De onderliggende beelden zijn NASA-materiaal en daarmee
publiek domein (NASA Visible Earth / Blue Marble, Earth at Night).
